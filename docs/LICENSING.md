## Why Apache-2.0 (not MIT / GPL)

- Permissive adoption for apps that embed the library  
- Explicit **patent grant** (and defensive termination)  
- Aligns with PaddleOCR (Apache-2.0) and much of the OFF app/SDK ecosystem  
- Copyleft (GPL/AGPL) would block many integrators; too early / wrong goal for this foundation  

## Third-party data

If/when Open Food Facts is integrated:

- Attribute ODbL / DbCL / CC-BY-SA as required  
- Do not mix proprietary barcode API dumps into a redistributed OFF-derived database  
- Per-pack expiry and user inventory are **not** OFF data  

Update `NOTICE` when adding redistributed attributions.
